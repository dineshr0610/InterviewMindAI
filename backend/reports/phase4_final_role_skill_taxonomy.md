# Phase 4: Final Role -> Skill -> Technology Taxonomy

## Python Developer
- **Python Core** (CORE)
  - *Data Structures*: Lists vs Tuples, Dicts, Sets
  - *Functions*: Closures, Decorators, Generators
  - *OOP*: Inheritance, Metaclasses, Dunder Methods
  - *Memory*: GC, GIL
- **Concurrency** (CORE)
  - *AsyncIO*: Event Loop, Coroutines
  - *Multithreading*: Threading, Locks
  - *Multiprocessing*: Processes, IPC
- **Web Frameworks** (IMPORTANT)
  - *FastAPI*: Dependency Injection, Pydantic, Routers
  - *Django*: ORM, Middleware, Signals
  - *Flask*: Contexts, Blueprints
- **Testing & QA** (IMPORTANT)
  - *pytest*: Fixtures, Mocking, Parametrization
- **Performance** (SECONDARY)
  - *Profiling*: cProfile, Memory Profiler
  - *Optimization*: Cython, Vectorization

## Frontend Developer
- **JavaScript** (CORE)
  - *Core JS*: Closures, Event Loop, Promises, Types
  - *Browser APIs*: DOM, Web Workers, Storage
  - *Performance*: Debouncing, Throttling
- **React** (CORE)
  - *State Management*: Hooks, Redux, Context
  - *Rendering*: VDOM, Concurrent Mode, SSR
  - *Performance*: Memoization, Code Splitting
- **HTML/CSS** (IMPORTANT)
  - *Layouts*: Flexbox, Grid
  - *Accessibility*: ARIA, Semantics
  - *Performance*: Critical Rendering Path
- **Web Security** (IMPORTANT)
  - *Security*: XSS, CSRF, CORS, CSP
- **Testing** (SECONDARY)
  - *Jest/RTL*: Unit Tests, Component Tests

## Java Developer
- **Java Core** (CORE)
  - *Collections*: HashMap, ConcurrentHashMap, Lists
  - *Memory*: Garbage Collection, JVM Internals
  - *OOP*: Interfaces, Polymorphism
- **Concurrency** (CORE)
  - *Multithreading*: Executors, Locks, ThreadLocal, Volatile
- **Spring Framework** (IMPORTANT)
  - *Spring Boot*: Auto-configuration, Actuator
  - *Spring MVC*: Controllers, Filters
  - *Spring Data*: JPA, Transactions
- **Testing** (IMPORTANT)
  - *JUnit/Mockito*: Unit Testing, Mocking

## Database Developer
- **Relational Databases** (CORE)
  - *PostgreSQL*: Indexing, VACUUM, MVCC
  - *MySQL*: InnoDB, Replication
  - *SQL*: Window Functions, Joins, CTEs
- **NoSQL Databases** (CORE)
  - *MongoDB*: Aggregation, Sharding
  - *Redis*: Data Structures, Persistence, Eviction
- **Architecture & Design** (IMPORTANT)
  - *Data Modeling*: Normalization, Denormalization
  - *Scaling*: Sharding, Replication, Partitioning
- **Optimization** (IMPORTANT)
  - *Query Tuning*: Execution Plans, Index Strategies

## DevOps / Cloud Engineer
- **Cloud Providers** (CORE)
  - *AWS*: EC2, S3, VPC, IAM, EKS, Lambda
- **Containerization** (CORE)
  - *Docker*: Images, Networking, Security
  - *Kubernetes*: Pods, Deployments, Services, Ingress, StatefulSets
- **CI/CD** (IMPORTANT)
  - *GitHub Actions / GitLab CI*: Pipelines, Runners
  - *Jenkins*: Declarative Pipelines
- **Infrastructure as Code** (IMPORTANT)
  - *Terraform*: State, Modules, Providers
- **Linux & Networking** (SECONDARY)
  - *Linux Core*: Processes, File Systems, Permissions
  - *Networking*: TCP/IP, DNS, Load Balancing
- **Observability** (SECONDARY)
  - *Monitoring*: Prometheus, Grafana, Logging

## Backend Developer
- **API Design** (CORE)
  - *REST*: Verbs, Status Codes, Pagination
  - *GraphQL*: Resolvers, N+1 Problem
  - *gRPC*: Protobufs, Streaming
- **Microservices** (CORE)
  - *Architecture*: Saga Pattern, Event Sourcing, Service Discovery
  - *Communication*: Message Queues, Event Driven
- **Caching** (IMPORTANT)
  - *Strategies*: Write-through, Cache Aside, Eviction
  - *Tools*: Redis, Memcached
- **Databases** (IMPORTANT)
  - *SQL & NoSQL*: Transactions, ACID, CAP Theorem, Connection Pooling
- **Security** (SECONDARY)
  - *Authentication*: JWT, OAuth2, Sessions
  - *Authorization*: RBAC, ABAC

## Data Analyst
- **SQL** (CORE)
  - *Advanced Queries*: Window Functions, CTEs, Subqueries
  - *Performance*: Query Tuning
- **Data Visualization** (CORE)
  - *Tools*: Tableau, PowerBI
  - *Concepts*: Chart Selection, Dashboard Design
- **Statistics** (IMPORTANT)
  - *Probability*: Distributions, A/B Testing, Hypothesis Testing
- **Python/R** (IMPORTANT)
  - *Pandas*: Data Manipulation, Aggregations, Cleaning

## AI Engineer
- **LLMs** (CORE)
  - *Architecture*: Transformers, Attention
  - *Prompting*: Few-shot, Chain of Thought, Zero-shot
- **RAG** (CORE)
  - *Components*: Vector DBs, Embeddings, Retrieval Strategies, Chunking
- **AI Agents** (IMPORTANT)
  - *Orchestration*: LangChain, LlamaIndex, Tool Use
- **MLOps for LLMs** (IMPORTANT)
  - *Deployment*: Serving, Quantization, Monitoring

## Machine Learning Engineer
- **ML Algorithms** (CORE)
  - *Supervised*: Trees, Linear Models, SVM
  - *Unsupervised*: Clustering, PCA
- **Deep Learning** (CORE)
  - *Architectures*: CNN, RNN, Transformers
  - *Optimization*: Gradient Descent, Loss Functions, Regularization
- **Model Training** (IMPORTANT)
  - *Process*: Cross Validation, Hyperparameter Tuning, Overfitting
- **MLOps** (IMPORTANT)
  - *Pipelines*: Data Drift, Model Registry, Feature Store, Serving

## Full Stack Developer
- **Frontend** (CORE)
  - *Frameworks*: React / Vue / Angular
  - *Core*: HTML/CSS/JS
- **Backend** (CORE)
  - *APIs*: REST / GraphQL
  - *Frameworks*: Node.js / Python / Java
- **Databases** (IMPORTANT)
  - *SQL / NoSQL*: Modeling, Querying
- **Architecture** (IMPORTANT)
  - *System Design*: Scalability, Security, Deployment
